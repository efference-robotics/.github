# Efference Robotics

Production intelligence for industrial robots.

An efference copy is the brain's internal copy of its own motor command, used to predict what a movement will do before it happens.
We build software in that spirit: robot systems whose behaviour is described once, checked before it runs, and measured once it does.

**What we care about**

- Correctness you can check, not just test.
- Reproducible builds, from source to deployed image.
- Evidence over claims: every result says whether it was proven, measured or simulated.

Our work is private for now.
